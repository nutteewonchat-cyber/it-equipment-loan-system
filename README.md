# ระบบยืม-คืนอุปกรณ์ไอที

เว็บแอปภาษาไทยสำหรับจัดการอุปกรณ์ คำขอยืม การอนุมัติ การคืน และรายงาน เหมาะสำหรับองค์กรหรือสถานศึกษา รองรับทั้งคอมพิวเตอร์และโทรศัพท์มือถือ

## ความสามารถหลัก

- Dashboard สรุปจำนวนอุปกรณ์และรายการเกินกำหนด
- ค้นหาและกรองอุปกรณ์ตามชื่อ ประเภท สถานะ และสถานที่
- เลือกยืมอุปกรณ์ได้หลายรายการ
- ป้องกันการจองอุปกรณ์ซ้ำในช่วงเวลาเดียวกัน
- ขั้นตอนอนุมัติ ปฏิเสธ ส่งมอบ และบันทึกคืน
- ตรวจสภาพ ระบุความเสียหาย ค่าปรับ และแนบรูปภาพ
- จัดการผู้ใช้งาน ประเภทอุปกรณ์ และสถานที่จัดเก็บ
- ส่งออกรายงานสำหรับ Excel และ PDF
- กำหนดสิทธิ์ผู้ดูแลระบบและผู้ใช้งานทั่วไป

## เทคโนโลยี

- Next.js / React / TypeScript
- Vinext และ Cloudflare Workers
- Cloudflare D1 สำหรับฐานข้อมูล
- Cloudflare R2 สำหรับรูปภาพความเสียหาย
- Drizzle ORM สำหรับโครงสร้างฐานข้อมูลและ Migration
- Tailwind CSS

## เริ่มต้นใช้งาน

ต้องใช้ Node.js เวอร์ชัน 22.13 ขึ้นไป

```bash
pnpm install
pnpm db:generate
pnpm dev
```

จากนั้นเปิด URL ที่แสดงใน Terminal

## คำสั่งสำคัญ

```bash
pnpm dev          # เริ่มเซิร์ฟเวอร์สำหรับพัฒนา
pnpm build        # ตรวจสอบและสร้างเวอร์ชัน Production
pnpm db:generate  # สร้าง Migration หลังแก้ไขโครงสร้างฐานข้อมูล
```

## ตัวแปรและข้อมูลสำคัญ

- ห้าม Commit ไฟล์ `.env`, Token, Secret หรือ Credential
- ไฟล์ Environment ถูกกำหนดให้ไม่ถูกติดตามใน `.gitignore`
- การ Deploy ต้องกำหนด D1 และ R2 binding ให้ตรงกับ `.openai/hosting.json`
- ผู้ใช้งานคนแรกของฐานข้อมูลใหม่จะได้รับสิทธิ์ Admin

## โครงสร้างข้อมูล

ตารางหลักประกอบด้วย:

- `users` — ผู้ใช้งานและสิทธิ์
- `equipment` — รายการอุปกรณ์
- `categories` — ประเภทอุปกรณ์
- `locations` — สถานที่จัดเก็บ
- `loan_requests` — คำขอยืม
- `loan_items` — อุปกรณ์ในแต่ละคำขอ
- `returns` — ประวัติการคืนและสภาพอุปกรณ์
- `system_settings` — การตั้งค่าระบบ

## ความปลอดภัย

การตรวจสิทธิ์ดำเนินการฝั่งเซิร์ฟเวอร์ การสร้างคำขอจะตรวจช่วงเวลาทับซ้อนก่อนบันทึก และการทำงานของผู้ดูแลระบบต้องผ่านการตรวจบทบาท Admin
